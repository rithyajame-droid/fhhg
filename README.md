# Rithtya Portfolio

A responsive personal portfolio website for Rithtya.

## Files
- `index.html` — main page
- `style.css` — design and responsive layout
- `assets/rithtya.jpg` — uploaded profile image used as the logo/avatar

## Deploy to Vercel
This is a static website and needs no build command.

### Option 1 — Vercel dashboard
1. Create a GitHub repository and upload these files.
2. Import the repository into Vercel.
3. Framework Preset: **Other**
4. Build Command: leave empty.
5. Output Directory: leave empty / project root.
6. Deploy.

### Option 2 — Vercel CLI
Install Vercel CLI, then run:
`vercel`
from this project folder.

## Customize
Edit the text in `index.html`. Replace `assets/rithtya.jpg` if you want another profile image.
